# Samikshya Sharma — Personal Portfolio

A personal portfolio website showcasing my journey as a Software Engineering student and Frontend Developer. It brings together my skills, projects, and contact information in one place.

## ✨ Features

- **About Me** — A short introduction and background.
- **Skills** — Technologies and programming languages I'm familiar with.
- **Projects** — A collection of my frontend projects with links to their source code.
- **Contact** — Links to connect with me professionally.
- **Responsive Design** — Designed to work across desktop and mobile devices.
- **Smooth Navigation** — Simple navigation with active section highlighting and scroll progress.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React, React Icons
- **Fonts:** Google Fonts

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/samikshyash1/Portfolio-Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio-Website
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
